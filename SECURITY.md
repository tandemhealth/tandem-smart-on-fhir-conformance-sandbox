# Security

This sandbox is a local developer tool. It is meant to run on your own machine,
bound to `127.0.0.1`, against test identities and synthetic data only. Never
point it at a production system.

## Reporting a vulnerability

If you find a security issue in this sandbox, email
**security@tandemhealth.ai** with a description and steps to reproduce. Please
do not open a public issue for security reports.

We aim to acknowledge reports within two working days.

## Scope

Issues in this repository are in scope. Issues in Tandem's products or hosted
services are handled separately; the same address reaches the right people.
